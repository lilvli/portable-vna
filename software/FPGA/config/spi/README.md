# SPI 配置 ROM 使用说明

本目录保存 LMK04828、AD9250 和 AD9144 的完整 SPI 写帧。每个 `.mem` 文件一行对应一个 ROM 地址，每行保存一帧已经打包完成的十六进制数据。

当前三个 `_example.mem` 文件只用于数字仿真，不能用于真实器件配置。顶层参数 `CONFIG_DATA_VALID` 默认保持为0，防止误发送。

正式替换步骤：

1. 按芯片手册和最终板级方案生成完整24-bit写帧。
2. 按真实写入顺序逐行写入对应 `.mem` 文件。
3. 检查行数、位宽、重复地址、更新触发寄存器和器件要求的延时。
4. 更新对应的 `ROM_DEPTH`、`ROM_WORD_COUNT`、`ROM_ADDRESS_WIDTH` 和文件名参数。
5. 同步更新 testbench 黄金数据并重新运行 XSim 与 OOC 综合。
6. 完成配置表评审后才把 `CONFIG_DATA_VALID` 设为1。
7. 上板后使用示波器/逻辑分析仪和寄存器读回分别形成硬件验证证据。

正式配置表建议由受控源文件和生成脚本确定性生成，并保存来源、器件完整型号、生成日期和 SHA-256。不要直接复制其他板卡的寄存器表并宣称适用于本项目。

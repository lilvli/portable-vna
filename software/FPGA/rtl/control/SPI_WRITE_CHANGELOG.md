# SPI 写控制器变更记录

## 2.0.0 - 2026-08-11

- 将“一套 SPI 主机加三路选择器”重构为三套独立 `spi_write_master`。
- 新增三套独立 XPM ROM；每个 ROM 地址保存一帧完整、已打包的发送数据。
- 新增通用 `spi_rom_device_sender`，负责一颗器件的 ROM 地址递增和整表发送。
- 总控固定按 LMK04828、AD9250、AD9144 顺序配置，三套物理总线不并发。
- 三颗器件分别参数化帧宽、ROM 深度/有效字数、初始化文件和 SCLK 分频。
- 新增 `CONFIG_DATA_VALID` 安全门，默认禁止把示例 ROM 用于真实配置。
- 自检改为验证三份 ROM、三套独立分频、12个24-bit 帧和整表顺序。

## 1.0.0 - 2026-08-11

- 新增通用、只写、Mode 0、MSB-first SPI 发送引擎。
- 支持每笔事务配置 1～64 bit 默认最大帧长。
- 支持每笔事务配置 SCLK 半周期分频。
- 新增 LMK04828、AD9250、AD9144 三组独立物理接口路由。
- 新增非法位宽、零分频、非法器件和 busy 重复 start 错误。
- 新增自动自检 testbench、独立仿真/OOC 综合脚本和最小例化。

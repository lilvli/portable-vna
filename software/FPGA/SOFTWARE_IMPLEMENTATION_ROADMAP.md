# 便携式矢网当前直采验证阶段软件实施路线

- 文档版本：V1.0
- 日期：2026-08-10
- 目标：用较短周期完成可学习、可复现、可逐级验证的一端口直采 VNA 软件原型，为最终上下变频扩展复用复数测量核心
- 关联规范：`FPGA_CODING_STANDARD.md`

## 1. 路线结论

本项目采用“两段式快速验证”：

1. **数字最小闭环：约 8～10 个工作日。** 形成可重复构建的 FPGA 工程，完成器件配置、JESD TX/RX、数字测试源、R/A 数据接收、基础复数处理和离线主机接口验证。
2. **5～100 MHz 硬件测量闭环：在硬件、耦合器和校准件齐备后约 5～7 个工作日。** 完成真实 SPI/时钟/JESD、Open/Short/Load 原始响应、SOL 校准和一次 S11 扫频演示。

总目标约为 **13～17 个工作日**。采购、板卡故障、许可证和未知硬件问题不计入固定工期；遇到这些情况应保持数字验证结果，不虚报硬件完成。

> **路线范围：** 上述工期只覆盖当前直采验证原型，不包含最终上变频、下变频、本振、滤波和射频开关的设计与实测。变频扩展是直采闭环通过后的独立里程碑，不反向扩大当前 MVP。

## 2. 学习与实施方法

每个阶段都执行相同的短循环：

```text
读官方资料和现有基线
  -> 画出接口、时钟和数据格式
  -> 只做一个最小功能
  -> 自检仿真
  -> 独立综合或 IP OOC
  -> 集成验证
  -> 记录结果、风险和下一阶段输入
```

学习重点不是一次写出完整仪器，而是掌握一条可复用的方法：

- 先确认硬件、时钟和协议参数；
- 再用官方 IP 建立数字链路；
- 再做确定性数据通路和算法；
- 最后接上位机、RF 前端和校准。

## 3. 软件总体边界

| 层次 | 首版责任 | 首版不承担 |
|---|---|---|
| FPGA 控制面 | 复位、SPI、时钟资格、JESD 启停、状态和错误 | 产品 UI、校准文件管理 |
| FPGA 数据面 | 激励数据、JESD、R/A 对齐、DDC、相干积分、复数点 | Smith 图、报表和复杂交互 |
| PC 上位机 | 扫频计划、设备控制、SOL 校准、显示和导出 | 实时接收原始 250 MSPS 双通道数据 |
| RF/硬件 | 分路、参考通道、耦合器、DUT 和 50 Ω 模拟输入 | 由软件推断但未经测量的模拟性能 |

首版推荐 FPGA 上传每个频点积分后的复数 `R` 和 `A`，PC 计算 `m=A/R`、应用 SOL 三项误差模型并显示 `S11`。这样接口带宽低，也保留调试和重新校准能力。

## 4. 快速实施阶段

### 阶段 0：工程与基线固定（0.5～1 天）

学习目标：理解 Vivado 工程、目标 part、源文件与生成物的区别。

工作内容：

- 保留现有 `prj/prj.xpr` 和 `rtl/top.v`，确认目标为 `xcku5p-ffvb676-2-i`、Vivado 2025.2。
- 建立架构、约束、配置、IP、仿真、脚本和任务目录。
- 固定 LMK、AD9250、AD9144、JESD 参数和 FMC lane 映射。
- 建立可重复创建工程的 Tcl；GUI 工程用于查看，不作为唯一构建入口。

完成判据：

- 空顶层可以通过编译；
- 工程可由 Tcl 重建；
- 参数和来源有书面记录；
- 没有开始硬件下载。

### 阶段 1：管理时钟、复位和最小可见性（1 天）

学习目标：掌握时钟缓冲、同步复位、计数器和 ILA/VIO 的基本使用。

工作内容：

- 建立独立管理时钟域；
- 实现外部复位的异步置位、同步释放；
- 加入心跳计数、状态寄存器和最小 ILA/VIO；
- 在仿真中验证复位时序和计数器行为。

完成判据：

- reset testbench 自动 PASS；
- 独立综合通过；
- 每个状态明确属于哪个时钟域。

### 阶段 2：LMK、AD9250、AD9144 配置面（1.5～2 天）

学习目标：掌握 SPI 时序、配置 ROM、设备启动顺序、读回、轮询和超时。

工作内容：

- 复用并适配经过核对的 SPI master、序列执行器和设备配置管理器；
- 配置顺序固定为 LMK→AD9250→AD9144；
- LMK 配置完成必须包含 PLL lock 轮询和同步收尾；
- ADC/DAC 配置包含寄存器来源、设备后缀和模式参数；
- 生成配置 ROM，不手工维护大段 case 表。

完成判据：

- SPI 时序、顺序、延时、读回成功、超时和失败路径仿真 PASS；
- 生成 ROM 可执行一致性检查；
- `all_config_done` 的语义明确为“配置事务完成”，不等于硬件链路通过。

### 阶段 3：官方 JESD TX/RX 模块级验证（2 天）

学习目标：掌握 JESD 参数、AXI4-Lite 配置、AXI4-Stream 数据、SYNC、SYSREF 和 lane 概念。

工作内容：

- 面向当前 part 重新生成官方 JESD204 TX/RX IP；
- TX 固定 AD9144 Mode 4，M2/L4/F1/K32，4×10 Gb/s；
- RX 固定 AD9250 M2/L2/F2/K32，2×5 Gb/s；
- 明确 ADC SYNC 为 FPGA→ADC，DAC SYNC0 为 AD9144→FPGA；
- 在 JESD 核与 PHY 之间实现集中 lane 重排；
- 分别运行官方 example、外围自检和 OOC 综合。

完成判据：

- IP 版本、参数、许可证状态均有记录；
- TX/RX 外围 testbench 自动 PASS；
- 两个模块 OOC 综合通过；
- 尚不宣称真实 JESD 链路通过。

### 阶段 4：共享 GT、时钟和系统实现（1.5～2 天）

学习目标：理解 GT Quad、COMMON/CHANNEL、QPLL/CPLL、专用参考时钟和最终 XDC。

工作内容：

- 使用系统级共享 PHY/GT，不把 TX/RX 的两个独立验证 PHY 同时接入同一 Quad；
- TX 采用 10 Gb/s/QPLL，RX 采用 5 Gb/s/CPLL；
- 使用 Bank 226 MGTREFCLK1 向 Bank 227 活动通道提供 125 MHz 参考时钟；
- 集成板级差分缓冲、SPI IOBUF、SYNC 和最终 lane 映射；
- 完整执行综合、布局布线、时序、DRC 和 CDC 检查。

完成判据：

- 所有活动 GT 位置和参考时钟路径可追溯；
- WNS/WHS 满足，0 DRC error；
- warning 逐项分成“已接受、待硬件确认、必须修复”；
- 可生成 bitstream，但仍属于数字实现证据。

### 阶段 5：数字测试数据和 R/A 可见性（1～1.5 天）

学习目标：掌握多样本并行数据、ROM/NCO、样本顺序、背压和分时钟域 ILA。

工作内容：

- 先使用确定的 50 MHz 多相测试源验证 DAC transport；
- 解包 AD9250 双通道 14-bit 样本并符号扩展；
- 统计 min/max、过零、削顶、有效样本和错误计数；
- TX、RX 分别使用本时钟域 ILA；
- 验证 `valid/ready` 背压期间数据保持。

完成判据：

- 测试源、transport、lane 重排、RX 解包和监测 testbench PASS；
- 数字样本顺序有黄金向量证明；
- 只称为数字数据通路通过，不称为模拟回环。

### 阶段 6：VNA 最小算法链（2 天）

学习目标：理解相干检波、复数表示、积分增益、定点位宽和 `A/R` 的意义。

工作内容：

- 从固定单频开始，实现 NCO 或与激励同源的数字 LO；
- R/A 两通道使用同一 LO 做 I/Q 解调；
- 加低通/累加和可配置相干积分；
- 明确实部、虚部、Q 格式、保护位、舍入、饱和和流水线延迟；
- 输出复数 `R`、`A` 及削顶、链路、积分有效标志；
- 用 Python/MATLAB 黄金模型比对幅度、相位和噪声下降趋势。

完成判据：

- 0°、90°、180°、负幅度、近零、削顶和噪声向量全部 PASS；
- R/A 通道延迟一致；
- 定点误差预算和积分长度有记录。

### 阶段 7：最小上位机与点数据协议（1～1.5 天）

学习目标：掌握控制面/数据面分离、帧协议、请求关联和测量记录。

工作内容：

- 首版使用 USB-UART，千兆以太网暂时保留；
- 定义初始化、状态、扫频配置、启动、停止、校准采集命令；
- 点记录至少包含请求号、点序号、频率、Nyquist zone、复数 R/A、积分数和状态标志；
- 实现最小 PC 脚本：发送命令、接收点记录、画幅相曲线、保存原始数据；
- 使用离线模拟设备验证丢帧、CRC、超时、乱序和重复请求处理。

完成判据：

- 无硬件时也能完成完整命令和点数据回放；
- 同一原始 R/A 文件可重复计算得到相同结果；
- UI 美化、Smith 图和网络控制不阻塞首个闭环。

### 阶段 8：5～100 MHz 硬件测量闭环（3～5 天，硬件就绪后）

学习目标：理解数字链路证据与真实时钟、JESD、RF 和校准证据的区别。

工作内容按门禁顺序执行：

1. 测量 VADJ、电源和复位电平；
2. 确认 LMK 锁定及 125/250/500 MHz、SYSREF；
3. 验证真实 SPI 写入/读回；
4. 验证 DAC JESD、固定单音和输出；
5. 验证 ADC JESD、R/A 输入、削顶和噪声；
6. 固定分路器、耦合器、线缆和 DUT 校准面；
7. 采集 Open、Short、Load 的复数 R/A；
8. 在 PC 求 SOL 三项误差并测量一个已知 50 Ω 负载或被测件。

完成判据：

- Open/Short/Load 原始响应可区分；
- 校准后 Load 目标约优于 -20 dB；
- Open/Short 幅度接近 1、相位相差约 180°；
- 不重新连接时，重复扫频幅度变化目标≤0.5 dB、相位≤5°；
- 记录环境、连接、配置、校准文件和原始 R/A，形成可重复证据。

## 5. 推荐里程碑

| 里程碑 | 预计时间 | 可展示结果 | 证据边界 |
|---|---:|---|---|
| M1 工程可复现 | 第 1 天 | Tcl 可重建空工程，规范和参数齐全 | 文档/编译 |
| M2 配置面完成 | 第 3 天 | 三器件配置流程仿真与综合 | 离线数字证据 |
| M3 JESD 模块完成 | 第 5 天 | TX/RX 官方 IP 和外围自检 | IP/OOC 证据 |
| M4 完整实现 | 第 7 天 | 完全布线、时序和 DRC 结果 | 未下载 bitstream |
| M5 复数点闭环 | 第 9～10 天 | 数字 R/A、DDC、积分和上位机回放 | 数字/离线证据 |
| M6 首个 S11 | 第 13～17 天 | 5～100 MHz SOL 校准和 DUT 曲线 | 真实硬件证据 |

## 6. 缩短周期的具体策略

1. 只保证首版 `5～100 MHz`，暂不处理 100～350 MHz Nyquist zone 拼接。
2. 首个接口使用 USB-UART，只传积分后的复数点，不上传连续原始 ADC 流。
3. 首个激励先使用固定 50 MHz，再扩展为可配置 NCO 扫频。
4. 先做幅相曲线和原始数据保存，Smith 图、Touchstone 和精美 UI 后置。
5. 复用受控参考工程的 SPI、配置、lane 映射和 JESD 外围思想，但所有 IP、XDC 和器件参数针对当前工程重新生成、核对。
6. 每个阶段只引入一个主要新变量；链路未稳定时不同时调算法和 RF。
7. 测试平台从第一天建立，避免最后依赖 ILA 人工猜测。
8. 每天结束留下可运行命令、PASS/FAIL 和已知问题，第二天从稳定基线继续。

## 7. 暂不进入首轮的功能

以下功能延后，避免拉长首个可用闭环：

- 100～350 MHz 多 Nyquist zone、频谱反转和跨区相位拼接；
- S21、双端口切换和全双端口校准；
- 千兆以太网连续数据流；
- 独立屏幕、按键、电池和便携机箱控制；
- 自动增益、多个 LNA/衰减档和仪器级动态范围；
- 完整 Touchstone/报告系统。

## 8. 主要风险与应对

| 风险 | 影响 | 处理 |
|---|---|---|
| JESD IP 许可证 | 评估 bitstream 可能超时 | 第 3 阶段检查许可证，生产前获取正式许可 |
| FMC lane/手册冲突 | 链路无法建链 | 以原理图+载板网名闭环核对，集中 lane 重排 |
| GT 参考时钟跨 Quad | 实现或上板不锁定 | 由系统级 GT Wizard 生成并检查实际路由 |
| VADJ/时钟电气未知 | 可能损坏或无法工作 | 硬件阶段第一步实测，不用文档假设替代 |
| 连续 SYSREF 杂散 | 降低模拟性能 | 首轮先保证确定性，后续实测后再决定脉冲模式 |
| A 通道信号过小 | 动态范围不足 | 首轮不装 LNA，记录噪声；再决定增益档 |
| ADC 前端资料缺口 | 输入阻抗和增益判断错误 | 补齐实装 ADA4930-2 数据手册并核对实板 |
| 算法位宽不足 | 幅相偏差或溢出 | 黄金模型、保护位、饱和计数和边界向量 |

## 9. 每阶段完成定义

一个阶段只有同时满足以下条件才算完成：

- 代码和文档符合 `FPGA_CODING_STANDARD.md`；
- 关键接口、时钟、复位、位宽和数据顺序已写清；
- 自动测试明确 PASS；
- 按阶段要求完成综合、实现或硬件证据；
- warning 和未验证项已记录；
- 下一阶段不需要猜测当前模块的接口和状态。

任何阶段若只有“代码已写”或“波形看起来差不多”，不得标记完成。
